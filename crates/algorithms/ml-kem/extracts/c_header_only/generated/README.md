# ML-KEM 768 C

This directory contains C code for ML-KEM 768, extracted from the Rust crate.
It is a header-only implementation that requires C++20 when building with C++.
For a version that is compatible with older C++ compilers (C++17), see
[`../../cpp_header_only/generated`](../../cpp_header_only/generated).

See [`libcrux-ml-kem/C-CODE.md`](../../../C-CODE.md) for how to extract,
build and test this code.
